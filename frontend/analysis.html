Detailed Technical Metrics

Formal statistical disparities: Disparate Impact (DI), Demographic Parity Difference (DPD), Equal Opportunity (EOD), and Equalized Odds (EODD)

DI METRIC
Disparate Impact (DI)
DI = Rateunpriv / Ratepriv

Ratio of positive outcomes between groups. Under EEOC guidelines, values below 0.80 (80%) indicate potential adverse impact.

DPD METRIC
Demographic Parity Diff
DPD = |Ratepriv - Rateunpriv|

Absolute difference in approval probability. Ideal parity is 0.00. Values exceeding 0.10 - 0.20 signify substantial disparity.

EOD METRIC
Equal Opportunity Diff
EOD = |TPRpriv - TPRunpriv|

Difference in True Positive Rates (TPR). Verifies whether qualified individuals from all groups enjoy an equal chance of favorable outcomes.

EODD METRIC
Equalized Odds Diff
EODD = max(|ΔTPR|, |ΔFPR|)

Comprehensive fairness test evaluating parity across both positive error (TPR) and negative false alarm (FPR) rates between groups.
